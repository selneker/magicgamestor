## 4. Thème — accueil épinglé sur les couleurs de la maquette

Les panneaux de l'accueil sont peints avec les tokens SLUSH (fixes, indépendants
du thème) mais les composants APP à l'intérieur (ProductCard, Skeleton…) lisent
les tokens shadcn qui basculent en sombre (crème-sur-crème sur les panneaux
fixes). Glue CSS `src/index.css` : sous `html.dark body[data-page="home"]`, tous
les tokens de l'app sont épinglés sur leurs valeurs LIGHT (shadcn + tokens
carte produit MGS-FE-CARDS + `--panel*`). L'accueil garde donc les couleurs
exactes de la maquette dans LES DEUX thèmes. Les autres pages gardent le thème sombre.

**Correctif du pin (vérifié sur build frais)** : le `<style>` inline anti-flash
de `public/index.html` pose `html.dark body { background:#2B2B2B; color:crème }`
(spécificité 0,1,2) et BATTAIT les règles Slush du body — en sombre, le body
restait #2B2B2B et le titre du hero (crème héritée) tombait sur le panneau
crème de la maquette. Le glue CSS neutralise ces deux déclarations sur
`html.dark body[data-page="home"]` (`background-color`/`color` rendus au CSS
Slush, spécificité 0,2,2) — vérifié au rendu : body #111111, hero encre sur
crème (`home-390-dark.png`).
