En-tête : montant + statut (couleurs identiques à la liste).
Carte : nom du jeu en texte seul (aucune icône) + bouton « Chat » (radius 8px, pas une pilule) → assistant IA.
Lignes produit / ID joueur / méthode / date ; sous la carte, un bouton icône seul (carré bordé 26 px, chevron, même logique que le repli mobile de l'admin) qui replie/déplie les détails existants (preuve, raison d'annulation…) — pas de texte « Détails ».
Encart IA (lime clair) : réponse courte de l'assistant quand la commande n'est pas terminée — jamais pour une commande livrée/remboursée/annulée.
Reçu téléchargeable : ouvre une vue reçu imprimable (logo, commande, montant, méthode, date, statut) → le client clique « Imprimer / Enregistrer en PDF » du navigateur. Aucune route backend, aucune dépendance : généré côté client à partir des données déjà affichées.
« Commander à nouveau » = pré-remplit un nouveau panier avec le même jeu/produit/ID, le client repasse par le flux normal (jamais une commande forcée). Masqué si une commande en attente de paiement existe déjà pour ce produit — bouton « Reprendre le paiement » à la place (logique existante).
